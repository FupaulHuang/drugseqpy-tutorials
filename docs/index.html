DRUGSEQPY / LEARNING PATH

Learn drugseqpy

Build a complete analysis from count matrices and plate metadata: inspect well quality and species identity, assess well-to-well repeatability, compare treatments within and across plates, and assess agreement with bulk RNA-seq.

These tutorials are written for new users. Each chapter explains the inputs, shows the Python calls, and connects the outputs to the next decision. You can read the same chapters as a website or directly on GitHub.

Follow the learning path

Step Chapter What you will be able to do
1 Getting started Install the package and run a small practice workflow.
2 Prepare inputs Align barcodes, validate counts and metadata, and check physical well positions.
3 Quality control Review library metrics, plate maps, marker expression, and optional read-level QC.
4 Mixed-species analysis Assign intended species and inspect purity, discordance, and reciprocal off-target signal.
5 Well-to-well repeatability Read well-correlation heatmaps and inspect treatment-matched replicate scatter plots.
6 Single-plate comparison Audit controls and estimate treatment effects within one plate.
7 Multi-plate comparison Audit controls, diagnose batch effects, measure reproducibility, and fit plate-adjusted treatment effects.
8 Bulk RNA-seq comparison Align features, compare matched reference profiles, and respect study and plate structure.
9 API reference Find function signatures, parameters, returns, and related workflow steps.

Understand the four sample labels

Dataset label Role in the tutorial Folder
Sample 1 Single-plate example and first plate in the multi-plate comparison data/sample_1/
Sample 2 Second plate with matching treatments and controls data/sample_2/
Sample 3 First mixed-species plate for QC and species review data/sample_3/
Sample 4 Second mixed-species plate for QC and species review data/sample_4/

Here Sample 1–4 are labels for plate datasets. Within a dataset, each observation is one well, and sample_id identifies that well. Sample 3 and Sample 4 form a different example from Sample 1 and Sample 2; do not pool all four for a treatment comparison.

The detailed chapters retain anonymized worked figures and result tables. The bundled synthetic practice data are independently generated and contain no measurements from the worked example. They teach the same input schema and analysis calls, but their numerical results will differ. The practice data include low-depth and mixed wells to make the review steps useful.

Choose a route

Start with Getting started to run the included practice data. If you already have count matrices, continue to Prepare inputs, then run the same workflow on a separate data directory. Mixed-species analysis is optional for a single-species experiment. For treatment analysis, start with Single-plate comparison, then extend to Multi-plate comparison when matched treatments and controls are available on another plate. The repeatability chapter helps review replicate consistency before treatment modeling. The bulk comparison extends Sample 3/4 QC to independently prepared references. Enrichment requires suitable local gene-set files; STARsolo read-level QC requires separate read statistics.
