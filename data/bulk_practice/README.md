# Synthetic bulk RNA-seq practice reference

These eight references were generated independently from random distributions; they contain no observed biological data. The Ensembl-shaped identifiers are synthetic matching keys. The study labels describe simulation groups only.

Human and mouse expression occupy separate rows. Blank cells mean unmeasured, not zero. Counts and FPKM columns retain distinct units. Use the dataset to exercise file formats and correlation calculations, not to draw conclusions about biology or methods.
